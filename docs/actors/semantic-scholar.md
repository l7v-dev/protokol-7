# Semantic Scholar Academic Knowledge Graph Harvester

`SemanticScholarActor` queries the Semantic Scholar Academic Graph (S2AG) API (`api.semanticscholar.org/graph/v1`) for scientific literature, AI-generated TLDR summaries, citation graphs, author profiles, and open-access PDF links across 200M+ research papers.

## Scope and Invariants

- **Multi-Identifier Paper Resolution**: Accepts Semantic Scholar Paper IDs (40-char hex), DOI (`10.1145/...`), arXiv IDs (`ARXIV:1706.03762`), PubMed IDs (`PMID:19872477`), Corpus IDs, or canonical web URLs.
- **AI-Generated TLDR Summaries**: Extracts automated one-sentence summaries generated by Semantic Scholar's specialized scientific language models.
- **Citation & Reference Graphs**: Traversable bi-directional citation links (`/citations` and `/references`) with metadata and author counts.
- **Author Metrics**: Provides author profiles with h-index, overall citation counts, paper counts, and affiliation histories.
- **Network Invariants**: Strict SSRF DNS-pinning validation (`SSRFGuard.validateUrlWithDns`), optional API key integration (`x-api-key`), timeout enforcement via `AbortController`, zero disk footprint.

## Configuration Options

| Option | Type | Default | Description |
|---|---|---|---|
| `action` | `"paper" \| "search" \| "author" \| "author_search" \| "citations" \| "references"` | `"paper"` | Query action |
| `paperId` | `string` | `""` | Paper identifier (S2 ID, DOI, arXiv, PMID) |
| `authorId` | `string` | `""` | Author identifier in Semantic Scholar |
| `query` | `string` | `""` | Search keyword expression |
| `fields` | `string` | `""` | Custom comma-separated S2 Graph API fields |
| `limit` | `number` | `10` | Maximum results to return (max 100) |
| `offset` | `number` | `0` | Pagination offset |
| `year` | `string` | `""` | Publication year or range filter (e.g. `2023`, `2020-2024`) |
| `apiKey` | `string` | `""` | Optional Semantic Scholar API key for elevated rate limits |
| `targetUrl` | `string` | `""` | Direct Semantic Scholar paper or author URL |
| `timeoutMs` | `number` | `30000` | Network request timeout in milliseconds |

## Endpoints

- **HTTP REST**: `POST /api/v1/semantic-scholar` (or bare alias `POST /semantic-scholar`)
- **MCP Tool**: `query_semantic_scholar`
