# Archive

Tamamlanmış görevlerin planları, yürütme kayıtları ve geçerliliği dolmuş konfigürasyon dosyaları.

## Klasörler

- `plans/` — Tamamlanan görevlere ait task planları. Aktif planlar için `docs/plans/`.
- `walkthroughs/` — Tamamlanan görevlerin yürütme doğrulama kayıtları. Son kayıtlar için `docs/walkthroughs/`.
- `GEMINI.md` — Eski agent kuralları dosyası. Geçerli kurallar `AGENTS.md` ve `context/code-standards.md` içinde.

## Aktif Bellek

- Görev belleği: `TASKS.md`
- Aktif planlar: `docs/plans/`
- Son walkthrough'lar: `docs/walkthroughs/`
