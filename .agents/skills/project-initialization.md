# Skill: Project Initialization & Skill Adoption

> **For AI Agents:** Use these instructions when adopting or initializing AI skills, context files, or MCP servers from `/etc/nixos/templates/aft`.

---

## 1. Skill & Context Copy Protocol
When adopting skills or AI context templates from `/etc/nixos`:
- Copy AI context templates to `context/`
- Configure `AGENTS.md`, `CLAUDE.md`, and `.mcp.json` in the root directory
- Ensure `context/progress-tracker.md` reflects current active milestones
